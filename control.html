현재 작업

연결 중

서버에 연결하면 모드를 선택할 수 있습니다.

2~4번 중단 → CSV 저장 → 1번에서 저장한 시작점으로 복귀 → 메뉴. 복귀 중 다시 중단하면 복귀도 멈춥니다.

CSV 그래프

CSV 기록 없음

휠: 확대·축소 · 드래그: 이동 · 더블클릭: 전체 보기

실험을 마치면 가장 최근 CSV를 자동으로 표시합니다.

CSV의 모든 행을 생략 없이 표시합니다. 겹쳐 보이는 점은 확대해 확인하세요.

X축: 시간(s) · 왼쪽 Y축: 로봇 거리(mm) · 오른쪽 Y축: 센서값(raw). 체크를 끄면 해당 선을 숨깁니다. 센서 빈칸은 선을 끊어 표시합니다.

아래 CSV 목록에서 파일을 누르면 그래프가 표시됩니다. 선택한 파일은 그대로 유지됩니다. 최신 CSV 보기로 자동 갱신에 복귀합니다. 실행 중에는 새로고침으로 저장된 기록을 확인하세요.

확인 중

stroke만큼 베이스 −Z로 하강합니다. 시작점이 stroke mm, 아래 끝점이 0mm입니다.

처음 실행하는 방법

로컬 웹 서버를 터미널에서 한 번 실행합니다.

source /opt/ros/humble/setup.bash
source /home/ur/ros2_ws/install/setup.bash
export ROS_DOMAIN_ID=125
ros2 run ur10_proxskin_test web_control

명령을 실행하면 브라우저에서 http://127.0.0.1:8765가 자동으로 열립니다. 드라이버 실행 → 실험 메뉴 실행 → 모드 선택 순서로 누릅니다.

기존 드라이버를 계속 사용해도 됩니다. 이 경우 ROS_DOMAIN_ID를 같게 맞추세요. 서버 시작만으로는 로봇이 움직이지 않습니다.
