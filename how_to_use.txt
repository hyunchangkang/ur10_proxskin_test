UR10 거리·XZ 평면 실험 실행 안내

브라우저용 안내: 같은 폴더의 how_to_use.html을 열면 모드별 설명과 경로 그림을 볼 수 있습니다.
실제 버튼 제어: control.html을 로컬 웹 서버에서 엽니다.

[웹 버튼으로 실행]

기존 실험 launch를 종료하고, 터미널에서 서버를 한 번 실행합니다.

source /opt/ros/humble/setup.bash
source /home/ur/ros2_ws/install/setup.bash
export ROS_DOMAIN_ID=125
ros2 run ur10_proxskin_test web_control

브라우저 주소: http://127.0.0.1:8765
서버 명령을 실행하면 기본 브라우저가 자동으로 열립니다.
브라우저를 자동으로 열지 않으려면 명령 뒤에 --no-browser를 붙입니다.

  ① 드라이버 실행: ros2 run urcb2_driver single_arm 실행
  ② 실험 메뉴 실행: ros2 launch ur10_proxskin_test proxskin_soc_test.launch.py 실행
  ③ 0~4번 모드 선택 -> 화면 설명 확인 -> 실행 버튼

드라이버가 이미 같은 ROS_DOMAIN_ID에서 실행 중이면 ②부터 진행합니다.
1번: 현재 위치 사용(y) / 위치 조정(n), ±Z 이동, 정렬(a), 조정 완료(e), stroke 저장.
2~4번: 왕복 횟수 선택, 4번은 정지 시간 선택 후 실험 실행.
중단 버튼: 2~4번 실험 중단 -> CSV 저장 -> 1번에서 저장한 시작점으로 복귀 -> 메뉴.
복귀 중 다시 중단하면 복귀도 멈춥니다. 0/1번 중단은 현재 작업만 취소합니다.
CSV 목록: 모든 실험 CSV를 표시합니다. 파일명을 클릭하면 그래프를 표시하고, 옆의 다운로드를 누르면 파일을 받습니다. 원본은 기존 data 폴더에 저장됩니다.
CSV 그래프: X축 시간(s), 왼쪽 Y축 2열 로봇 거리(mm), 오른쪽 Y축 3열 센서 raw 값.
각 체크박스로 2열/3열 선을 각각 켜고 끕니다. 마우스를 올리면 시간과 값을 볼 수 있습니다.
선택한 파일은 새 기록이 생겨도 유지됩니다. 최신 CSV 보기를 누르면 최신 파일 자동 갱신으로 돌아갑니다. 실행 중에는 새로고침으로 저장된 값을 봅니다.
그래프 위에서 휠로 확대·축소, 드래그로 이동합니다. 확대/축소 버튼도 사용할 수 있으며, 전체 보기 또는 더블클릭으로 범위를 초기화합니다.
CSV의 모든 행을 생략 없이 표시합니다. 확대하면 해당 구간의 원본 점을 모두 확인할 수 있습니다. 센서 빈칸은 선을 끊어 표시하며 원본 CSV는 변경하지 않습니다.

서버와 메뉴 실행만으로는 이동하지 않습니다. 모드 실행 또는 Z 이동/정렬 버튼으로 움직입니다.
HTML 파일을 직접 열면 서버 시작 방법이 표시되며, 실제 제어는 위 localhost 주소에서 합니다.
브라우저 탭을 닫아도 작업은 계속됩니다. 서버 터미널의 Ctrl+C는 웹에서 켠 실험과 드라이버를 종료합니다.
외부 터미널에서 켠 드라이버는 해당 터미널에서 종료합니다.
웹 제어와 별도 실험 launch를 동시에 실행하지 않습니다.

[터미널에서 실행]

1. 드라이버 실행 — 터미널 A

source /opt/ros/humble/setup.bash
source /home/ur/ros2_ws/install/setup.bash
export ROS_DOMAIN_ID=125
ros2 run urcb2_driver single_arm

2. 실험 메뉴 실행 — 터미널 B

source /opt/ros/humble/setup.bash
source /home/ur/ros2_ws/install/setup.bash
export ROS_DOMAIN_ID=125
ros2 launch ur10_proxskin_test proxskin_soc_test.launch.py

ROS_DOMAIN_ID는 두 터미널에서 같아야 합니다. 125는 실행 예시이며,
이미 실행 중인 드라이버가 다른 값을 사용하면 실험 터미널도 그 값으로 맞춥니다.

권장 순서: 0번 기본 자세 -> 1번 시작점 설정 -> 2/3/4번 실험.
현재 위치에서 바로 설정하려면 0번을 건너뛰고 1번을 선택합니다.

3. 모드별 동작

0 — Move to base pose
    J1/J6는 현재 각도를 유지하고 J2~J5를 [-90, -90, -90, 90]도로 이동합니다.
    EE의 Z축 주위로 회전하는 마지막 관절 J6(wrist_3)를 고정합니다.
    시작점을 저장하지 않습니다. 도착 후 1번에서 시작점을 설정합니다.

1 — Set up start position and distance
    Use current position as start? (y/n, q to cancel)

    y: 현재 위치를 사용합니다.
       Start distance (mm): 에 원하는 거리를 입력합니다.
       100, 200, 300, 125.5 등 모든 양수 mm를 받으며 소수도 허용합니다.
       0, 음수, 숫자가 아닌 값은 다시 입력하도록 안내합니다.
       마지막으로 TCP XYZ와 J6 각도를 유지하며 툴 Z 기울기를 월드 Z에 맞춥니다.
       yaw/X/Y 방향을 90도 단위로 정렬하지 않습니다.
       월드 yaw 각도 자체는 지정하지 않고 J6 각도를 유지합니다.
       정렬 후 실제 TCP XYZ/RPY, 관절값 6개, 선택한 거리 기준을 저장합니다.

    n: 현재 위치를 조정합니다.
       펜던트로 베이스 Z축 방향을 조정하거나 터미널에 +10, -1처럼 입력합니다.
       터미널 입력은 정수 mm입니다. +는 베이스 +Z, -는 베이스 -Z입니다.
       터미널로 Z를 이동할 때 현재 X/Y, TCP 방향, J6 각도를 유지합니다.
       입력 대기 중에는 관절 유지 명령을 보내지 않아 펜던트 조정이 가능합니다.

    a: Z adjustment:에서 입력하면 현재 위치에서 즉시 툴 Z 기울기를 정렬합니다.
       펜던트나 Z 입력으로 움직인 후의 현재 TCP XYZ와 J6 각도를 유지합니다.
       정렬이 끝나면 Z adjustment:로 돌아와 조정을 계속할 수 있습니다.
       이때는 시작점 파일을 저장하지 않습니다.

    e: 위치 조정을 끝내고 현재 위치 사용 여부 질문으로 돌아갑니다.
       다시 y를 선택하고 거리(mm)를 입력해야 시작점이 저장됩니다.
       a로 이미 정렬했어도 거리 입력 후 마지막 정렬을 다시 확인하고 저장합니다.

    q: 저장 없이 설정을 종료하고 메뉴로 돌아갑니다.
       기존 시작점 파일은 유지됩니다.

    1번은 기본 관절 자세로 자동 이동하지 않습니다.
    기존 5번의 수동 Z 조정은 1번에 통합되었습니다.

2 — Z down / up
    저장한 시작점으로 복귀한 뒤 베이스 -Z로 하강하고 시작점으로 돌아옵니다.
    X/Y와 TCP 방향을 유지합니다. 왕복 횟수는 1~100회 중 입력합니다.
    예: 200mm로 저장하면 현재 시작점에서 200mm 내려갔다 복귀합니다.
    100mm, 300mm, 소수 거리도 같은 방식으로 적용됩니다.

3 — X-Z scan (Y fixed)
    각 X 위치에서 2번 Z 왕복을 마친 뒤 시작 Z 높이에서 다음 X 위치로 이동합니다.
    Y와 TCP 방향을 유지하며, 왕복 횟수는 각 X 위치에 적용됩니다.
    기본 범위: 저장한 시작 X 기준 +300mm -> -300mm, 전체 600mm.
    기본 간격: 1mm = 0.1cm, 총 601개 X 위치.
    완료 시 마지막 X 위치(-300mm)의 시작 Z 높이에서 종료합니다.

4 — Z down / up with 1 cm stops
    2번과 같은 경로에서 하강·상승 모두 10mm마다 정지합니다.
    왕복 횟수와 정지 시간을 입력합니다. 기본 정지 시간은 2초입니다.
    10mm의 배수가 아닌 거리도 끝점까지 이동합니다.
    예: 125.5mm라면 120mm 정지 위치에서 5.5mm 더 내려가 끝점에 도착합니다.
    상승할 때는 같은 정지 위치들을 거쳐 시작점으로 돌아옵니다.

메뉴 실행에서는 각 모드가 끝나면 번호 선택 화면으로 돌아옵니다.
2~4번 실행 중 q 키를 누르면 취소합니다. Enter는 필요 없습니다.
시작점 복귀, 경로 계산, 이동, 끝점 도달 대기, 4번 정지 시간 중에도 사용할 수 있습니다.
실험 이동을 중단하고 그때까지의 CSV를 닫은 뒤, 1번에서 저장한 6개 관절 위치로 저속 복귀합니다.
실험 시작 전과 같은 관절 복귀 경로이며, 복귀 중에는 TCP XYZ와 방향이 함께 바뀔 수 있습니다.
도착 후 번호 선택 메뉴로 돌아옵니다. 복귀 동작은 CSV에 추가하지 않으며 드라이버는 계속 실행됩니다.
복귀 중 q를 다시 누르면 복귀도 멈춥니다. 피드백/안전 검사 실패 시에는 복귀를 중단합니다.
메뉴로 돌아오기 전에 터미널 입력 상태를 복원합니다.
메뉴의 1번과 2번 사이에는 빈 줄을 표시합니다.
2~4번의 이동 거리는 1번에서 저장한 값으로 정해집니다.

4. 좌표 기준과 시작점 파일

툴 Z 기울기 정렬 기준: 월드 Z축. 정렬 중 TCP XYZ/J6 유지.
Z 하강과 X 열 이동 기준: 로봇 컨트롤러의 베이스 축.
현재 설정의 월드/베이스는 Z축 기준 180도 차이여서 X/Y 방향은 반대이고 Z는 같습니다.

시작점 파일:
/home/ur/.ros/ur10_proxskin_test/experiment_start.json

새 파일은 버전 2이며 start_distance_mm, tcp_pose, joint_rad 등을 저장합니다.
이전 파일에는 거리 기준이 없으므로 새 1번에서 다시 저장해야 합니다.
2~4번은 저장된 관절값으로 시작점에 복귀한 뒤 실험합니다.
시작점 복귀는 관절 이동이므로 이 구간에서는 XYZ가 바뀔 수 있습니다.

하단·상단·X/Z 전환점에서 실제 TCP 도달을 확인합니다.
위치 오차 0.1mm 이하, 방향 오차 0.1도 이하가 0.25초 유지되어야 진행합니다.
5초 내에 도달하지 못하면 실험을 중단하고 그때까지의 CSV를 저장합니다.

5. CSV 저장

저장 폴더:
/home/ur/ros2_ws/src/ur10_proxskin_test/data/

모드마다 새 파일을 만듭니다.
2번: experiment_vertical_날짜_시간_마이크로초.csv
3번: experiment_columns_날짜_시간_마이크로초.csv
4번: experiment_stepped_날짜_시간_마이크로초.csv

열: time_s,robot_distance_mm,sensor_value
1열: 첫 기록부터 경과 시간(초), 소수점 6자리.
2열: 실제 관절 피드백으로 계산한 TCP Z 거리(mm), 소수점 2자리.
3열: 센서값. CAN 0x41의 앞 4바이트(big-endian uint32)를 Ethernet으로 수신합니다.
시간·로봇 거리·센서값은 100Hz(10ms) 타이머에서 같은 행에 기록합니다. 로봇 제어는 125Hz입니다.
시간은 실제 기록 시각이며 작은 주기 오차가 반영됩니다.
센서가 100Hz보다 느리면 새 값이 들어오기 전까지 최근 유효 센서값을 반복 기록합니다.
실험 시작점 복귀와 준비가 끝나 실제 실험을 시작할 때 파일을 엽니다. 0/1번에서는 기록하지 않습니다.
기본 서버: 192.168.253.225:4001. Prox_sensor_React와 같은 TCP 클라이언트/14바이트 수신 방식입니다.
처음에는 CAN 0x41의 최신 값이 들어올 때까지 기다립니다. 단절 또는 0.5초 넘게 오래된 값은 빈칸입니다.

거리 계산: 저장한 거리 기준 + (현재 TCP Z - 시작 TCP Z) * 1000.
300mm 기준의 목표: 300.00 -> 0.00 -> 300.00mm.
200mm 기준의 목표: 200.00 -> 0.00 -> 200.00mm.
100mm 기준의 목표: 100.00 -> 0.00 -> 100.00mm.
125.5mm 기준의 목표: 125.50 -> 0.00 -> 125.50mm.
CSV는 실제 측정값을 기록하므로 끝점 값에 작은 오차가 남을 수 있습니다.
시간 기록에는 별도의 프레임 번호나 절대 시각 열이 없습니다.
0/1번은 시작 준비 과정이며 실험 거리 CSV를 만들지 않습니다.

6. 실행 옵션

3번의 X 간격을 1cm로 변경하고 메뉴 실행:
ros2 launch ur10_proxskin_test proxskin_soc_test.launch.py spacing_mm:=10

3번의 X 범위를 시작 X부터 +X로 300mm, 간격 10mm로 변경하고 메뉴 실행:
ros2 launch ur10_proxskin_test proxskin_soc_test.launch.py x_direction:=positive x_span_mm:=300 spacing_mm:=10

메뉴 없이 현재 XYZ/J6를 유지하며 툴 Z를 정렬하고 200mm 시작 거리 저장:
ros2 launch ur10_proxskin_test proxskin_soc_test.launch.py mode:=capture start_distance_mm:=200
start_distance_mm은 양수 mm이며 소수를 허용합니다. 자동 실행의 기본값은 300mm입니다.

메뉴 없이 저장한 거리 기준으로 Z 왕복 2회:
ros2 launch ur10_proxskin_test proxskin_soc_test.launch.py mode:=vertical repeat_count:=2

메뉴 없이 10mm마다 3초 정지하며 Z 왕복 2회:
ros2 launch ur10_proxskin_test proxskin_soc_test.launch.py mode:=stepped repeat_count:=2 dwell_seconds:=3

mode를 직접 지정한 실행은 수행 후 launch가 종료됩니다.
이 경우에도 2~4번 실행 중 q로 취소할 수 있지만, 메뉴 대신 launch가 종료됩니다.
센서는 기본 활성화입니다. 센서 없이 로봇만 실행하려면 enable_ecan:=false를 붙입니다.
