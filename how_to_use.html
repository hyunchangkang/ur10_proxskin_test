UR10 실험 실행 가이드

터미널 두 개를 켜고, 시작점을 저장한 뒤 원하는 실험을 선택하세요.

안내 · 경로 미리보기 / 로봇 연결 없음
0 기본 자세→1 시작점 + stroke 저장→2 · 3 · 4 실험 선택
현재 위치에서 시작하려면 0번을 건너뛰고 1번부터 진행하세요.

01. 터미널 두 개 실행

A. 드라이버 먼저

source /opt/ros/humble/setup.bash
source /home/ur/ros2_ws/install/setup.bash
export ROS_DOMAIN_ID=125
ros2 run urcb2_driver single_arm

B. 실험 메뉴

source /opt/ros/humble/setup.bash
source /home/ur/ros2_ws/install/setup.bash
export ROS_DOMAIN_ID=125
ros2 launch ur10_proxskin_test proxskin_soc_test.launch.py

두 터미널의 ROS_DOMAIN_ID를 같게 맞춥니다. 위 명령은 125 기준입니다.

02. 번호를 누르면 무엇이 되나요?

아래 버튼은 설명을 바꿉니다. 실제 로봇의 모드는 터미널에서 선택합니다.

0. 기본 자세로 이동

J1/J6는 현재 각도를 유지하고, J2~J5를 기본 각도로 이동합니다. 시작점 저장은 1번에서 진행합니다.

mm

이 입력은 그림의 예시만 바꿉니다. 실제 stroke는 터미널 1번에서 저장합니다.

2·3·4번 실행 중 취소: 실험 터미널에서 q만 누르세요. Enter는 필요 없습니다.
실험 중단 → CSV 저장 → 1번에서 저장한 시작점으로 저속 관절 복귀 → 메뉴. 복귀 중 q를 다시 누르면 복귀도 멈춥니다.

완료 후에도 모드 선택 메뉴로 돌아옵니다. 드라이버 터미널은 계속 켜 둡니다.
2·3·4번의 시작 자세 복귀는 관절 이동이므로, 복귀 구간에서는 XYZ가 바뀔 수 있습니다.

03. 무엇이 저장되나요?

2·3·4번마다 data 폴더에 새 CSV를 만듭니다.

열저장 내용
time_s첫 기록부터 경과 시간 · 초
robot_distance_mm실제 TCP Z 기준 거리 · mm, 소수점 2자리
sensor_value센서값 · CAN 0x41 front 수신

100Hz(10ms)마다 시간·실제 TCP Z 거리·센서값을 함께 저장합니다. XYZ/RPY 전체는 CSV에 저장하지 않습니다.

시작점 XYZ/RPY·관절값·stroke 저장 파일:
/home/ur/.ros/ur10_proxskin_test/experiment_start.json

실험 CSV: experiment_vertical_… / experiment_columns_… / experiment_stepped_…

버튼으로 로봇 제어

로컬 웹 서버를 한 번 켜면 버튼으로 실행할 수 있습니다.

HTML 버튼→로컬 제어 서버→ROS2 · 드라이버
source /opt/ros/humble/setup.bash
source /home/ur/ros2_ws/install/setup.bash
export ROS_DOMAIN_ID=125
ros2 run ur10_proxskin_test web_control

명령 실행 시 브라우저가 자동으로 열립니다. 제어 화면 열기 →
드라이버 실행 → 실험 메뉴 실행 → 모드 선택 → 실행

제어 화면은 시작점 설정, Z 조정, 정렬, 실험 중단과 CSV 다운로드를 지원합니다. 기존 실험 launch는 종료한 뒤 사용하세요.
